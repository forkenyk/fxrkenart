# FXRKENART

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Cloudflare

- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Root directory: `/`

The intro uses Vietnam time:

- 06:00–17:59: white background and black logo.
- 18:00–05:59: black background and white logo.

Timing is configured at the top of `src/main.tsx`.
